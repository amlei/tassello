# 九漾 Onda · 方向 C · 色板 Mosaic

三种视觉语言之一：类型色大号平涂色块拼成不对称网格，大字号 + mono 数据，无渐变无阴影堆叠。

骨架经过一次重做：原来的首页是四列色板墙（bento），四类内容各自很多时扛不住 ——
容量被写死成「一屏 × 4 列」，最长的那一列决定整页高度，另外三列往下全是空槽。
现按 B+C 方案改成左栏 + 单列表：视觉语言不变（仍是 C 的色板），换掉的是结构。

重做前的四列 bento 版本可从 git 取回：

```bash
git show HEAD:designs/onda-explore/directions/mosaic/index.html > /tmp/mosaic-bento.html
git show HEAD:designs/onda-explore/directions/mosaic/jsx/home.jsx > /tmp/home.jsx   # 被删掉的 bento 首页
```

## 跑起来

```bash
python3 -m http.server 4311 --directory designs
# http://localhost:4311/onda-explore/directions/mosaic/index.html
# 对比画布：http://localhost:4311/onda-explore/Explore.html
```

原型是 React + Babel 多文件形式（`jsx/*.jsx`），必须走 HTTP，`file://` 打不开。

## 视觉与改动

**本轮（对齐 apps/web 实际代码）**：

- 中性风格：底色白、发丝线（1px `--line`）、一个功能蓝（`--accent:#2383E2`），
  水墨纸色（`#FAFAF6/#16130E`）与 2px 墨色描边全部退场；类型色只留在小面积（方块/chip）
- 深浅主题：`data-theme="dark"` 全套灰阶翻转，设置里新增「外观 · 主题色」三段选择器
  （浅色 / 深色 / 跟随系统），偏好存 localStorage，首屏防闪烁脚本在 `index.html`
- 删掉「全部稿子」：左栏只有四类型 + 发布队列；新建内容收进左栏顶部的蓝色主按钮
- 四类全部卡片化：文章 / 音频 / 视频不再用行，统一进 212px 卡片网格；
  文章与音频的封面 = 三行摘要直接当封面（音频加青色小三角 + 时长），视频 = 16:9 播放封面，
  贴图 = 2×2 拼贴（1 张独占 / 2 张各半 / 3 张首格横跨）
- 卡片状态：封面左下角「发布中」accent 药丸，标题行「已发布」绿色贴纸（发布事实仍只在队列）
- 素材拖拽归一：编辑页图片素材条换掉 HTML5 拖拽，改用与贴图页同一套长按拖拽
  （`dnd.jsx` 的 `useLongPressReorder`：按住 220ms 拎起、其余缩略图 FLIP 让位、松手落位）；
  角上的 × 挂在 `.w-tileacts` 里，删除不会把长按也吃了
- 素材可删：贴图的每张缩略图悬停出 ×（正文里引用它的图块一并清掉）；
  视频 / 音频素材悬停出 ×，删掉回到「未上传」的虚线上传槽，点一下再传；
  手机预览跟随：没传文件时预览里不出现封面 / 播放条；新建的视频 / 音频稿从「上传」开始
- 素材铺满写作列：视频封面、音频播放条、上传槽统一 `width:100%; max-width:560px`，
  196px 的小封面和 440px 的小播放条退场 —— 素材区不再在大屏上留一整块空白
- 单色品牌跟主题翻转：X 的方块/文字改走 `--plat-x`（亮色黑标、深色白标），
  淡色底改用 `color-mix`（平台色是 CSS 变量时字符串拼 `+"33"` 会失效）
- 设置瘦身：删掉 sheet 副标题与「点一行看账号详情」；账号行去掉 kind（订阅号/个人号…），
  平台名固定 72px，中间的账号名一列对齐（与实现同宽）
- 预览区只读但可交互：正文不可编辑，链接点了新开页（不把原型带走）；
  预览里的视频 / 音频能就地播 —— 点封面或按钮播放/暂停、点进度条跳播、假播放推进时间与进度
- 深色主题修补：基础 `button` 补 `color:inherit`（平台账号行的文字此前不随主题）；
  发布状态浮条固定深炭底白字（不再随主题翻成浅底白字看不清）；
  预览音频的播放/暂停图标改成两枚真实元素由 React 切换，不依赖伪元素显隐
- 设置底部：完成按钮浮在滚动区上、通道全透明（滚动区补了底部留白），不再挡住滚过的内容
- 编辑页瘦身：去掉类型 chip；加手动保存按钮（脏了才可点，⌘S 同效）；音频上传槽改矮条
  （与传完后的播放条同高，不再是 16:9 大空框）；素材条只留「N 张」，去序号与操作描述
- 卡片去重复数据：文章/贴图卡片不再显示字数；视频卡的时长只留在封面上，标题下不重复
- 标签是完整 token：#标签 span 不可编辑（contenteditable=false），标签后继续打字落在标签外，
  不会被吞进标签里
- 预览区按手机交互：滚动条全部隐藏；贴图缩略图定宽 72px，按住拖动横滑（不是电脑端滚动）
- 文案再瘦身：删掉「长按方块可拖动排序」「N 个发布动作 · 发布事实只此一处」「发布在后台跑，
  不阻塞界面」「N 个平台」「N 字 / #话题 N 个」「13/15 已获取」「N 张」—— 界面只留数据，不留功能说明书；
  发布弹层的说明句与「将创建 N 个发布任务」一并删除；「假播放」「封面占位」「实时更新/实时出现」、
  各处 tooltip 行为说明、空态引导语全部移除，空态只留一句事实（如「还没有内容」「队列为空」）
- 重新获取账号：从一枚小描边 pill 升级成整行宽、文字居中的主色 CTA（获取失败时的主要动作要一眼可见）
- 引用彻底可退出：blockquote 改为手动包 / 解壳，不走 formatBlock —— Chrome 会把壳留下来
  （「后面全是引用且清不掉」）；空引用回车、引用末尾回车、引用行首退格、工具栏再点一次都能出去；
  引用里换标题 / 正文也会先解壳
- 图块不再挂「配图」角标
- 编辑工具栏吸附：`position:sticky` 钉在写作列顶部，长文往下滚格式工具始终在；
  顶距从容器 padding 挪到首子元素 margin，否则工具栏会卡在 padding 之下露出内容
- 发布浮条回到跟随主题（`--ink/--paper` 反色），两种模式对比度都够
- 粘贴不再失焦：paste 一律拦截 —— 图片走素材插入，文字转成规范 HTML 后 insertHTML 插入，
  不让浏览器塞脏标签触发整块 DOM 重写；高亮重写时也会把焦点还给编辑区
- 保存收敛为一枚状态按钮：已保存 = 灰态不可点、未保存 = 主色「保存」、保存中 = 「保存中…」；
  去掉时间戳与状态文字，自动保存也移除（改为纯手动 + ⌘S）
- 未保存离开有确认：返回 / 切换栏目 / 新建 / 队列 / 浮条都会被拦下，弹三选一
  （取消 / 不保存并离开 / 保存并离开）；刷新或关标签页走 beforeunload 原生确认

**沿用**：色板 token（`--blue/--magenta/--orange/--cyan/--green`）、大字号 + mono 数据、
九宫格 Logo 语言、`m-*` 组件类；编辑页、发布弹层、预览手机屏的结构未动，只换了皮肤。

## 这一版判断了什么

1. 类型是维度不是结构：左栏第一组放四类，第二组放发布队列；「全部稿子」已删（与实现一致）。
2. 发布状态只有一个实体：发布事实全部记在发布队列，稿子不挂状态字段，卡片只保留「发布中」「已发布」两个从队列推导的信号。
3. 预览只在编辑页：卡片不挂预览入口，想看发出去什么样就打开稿子。
4. 版式跟内容形状走，但壳统一：四种类型共用一个卡片壳（1px 发丝线 + 14px 圆角 + hover 浮起），
   封面各自长脸 —— 文章/音频摘要封面、视频播放封面、贴图拼贴封面。
5. 栏底只留一个设置入口：外观、平台账号与默认发布名单都收在设置里；只有凭据缺失时该行才冒出一个数字。
6. 平台账号一行说的是「哪个账号」：账号名 + 身份常显；点一下，凭据卡从设置弹窗**外侧**浮出来。
   左列账号往左弹、右列往右弹，带箭头指着被点的那一行，不顶走下面的名单；窗口太窄放不下时退回视口内。
7. 默认发布平台四行各成一条横带（上下 18px 留白 + 一条细线），不再只靠行间距分开。
8. 平台方块三种面貌：**选中 = 平台色填满** + 角上一枚 accent 勾；没选中 = 同色淡底（`color + "33"`，保留平台身份）；
   凭据没拿到 = 中性灰。默认名单与发布弹层共用同一套规则。
9. 发布队列里状态长在平台方块上：一篇稿子一行，进行中从方块底部涨水位，已发布右上角一枚勾且整块是直达链接，
   出问题整块换成统一的错误色、点一下重试。
10. 错误色只有一种：发布失败、凭据获取失败、超限预检共用它；橙色回归成纯内容色（视频）。
11. 内容列只有一条宽度：头部与网格共用 `.w-canvas`（上限 1560px 居中）。
12. 规模：筛选 O(n)、排序 O(n log n)；过千条需要窗口化渲染（本原型未做）。
13. 贴图支持长按拖拽排序：按住 220ms 拎起（轻点仍是打开这篇），拖动时其余格子实时让位（FLIP），松手滑回槽位落位。
    一拖就把排序档切到「自定义顺序」。搜索中与按标题排时不开拖动。
14. 标题全套按 Apple HIG 的层级做法，只留两级（Title 1 / Title 2），层级只靠字号差：
    一级 28px/700（栏目名、正在编辑的稿子），二级 22px/700（弹层标题），行/格子标题 15–17px/700。
15. 主题切换器与实现（`apps/web/components/theme.tsx`）同源：localStorage key 同为 `onda-theme`，
    「跟随系统」由首屏脚本常驻监听，切到浅/深只落偏好。
16. 音频＝播客：`audio` 只留给播客平台（小宇宙 / 喜马拉雅 / 荔枝播客 / 蜻蜓FM）和微信公众号的语音消息。
