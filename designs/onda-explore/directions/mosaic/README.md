# 九漾 Onda · 方向 C · 色板 Mosaic

三种视觉语言之一：类型色大号平涂色块拼成不对称网格，大字号 + mono 数据，无渐变无阴影堆叠。

骨架经过一次重做：原来的首页是四列色板墙（bento），四类内容各自很多时扛不住 ——
容量被写死成「一屏 × 4 列」，最长的那一列决定整页高度，另外三列往下全是空槽。
现按 B+C 方案改成左栏 + 单列表：视觉语言不变（仍是 C 的色板），换掉的是结构。

重做前的四列 bento 版本可从 git 取回：

```bash
git show HEAD:designs/onda-explore/directions/mosaic/index.html > /tmp/mosaic-bento.html
git show HEAD:designs/onda-explore/directions/mosaic/jsx/home.jsx > /tmp/home.jsx   # 被删掉的 bento 首页
```

## 跑起来

```bash
python3 -m http.server 4311 --directory designs
# http://localhost:4311/onda-explore/directions/mosaic/index.html
# 对比画布：http://localhost:4311/onda-explore/Explore.html
```

原型是 React + Babel 多文件形式（`jsx/*.jsx`），必须走 HTTP，`file://` 打不开。

## 视觉与改动

- 沿用：色板 token（`--blue/--magenta/--orange/--cyan/--green/--ink/--paper`）、2px 墨色描边、
  大字号 + mono 数据、九宫格 Logo 语言、`m-*` 组件类
- 改动：删掉顶栏与四列 bento（`.m-topbar/.m-bento/.m-card*`），换成左栏 + 单列表骨架（`.w-*`）
- 未改：编辑页、发布弹层、预览手机屏（`.m-editor/.m-sheet/.m-phone`）

| `jsx/{editor,tasks,publish,bits,icons}.jsx` | 编辑器、发布队列、发布弹层与共享组件 |

## 这一版判断了什么

1. 类型是维度不是结构：左栏第一组放四类，第二组放跨类型入口（全部稿子、发布队列）。
2. 发布状态只有一个实体：发布事实全部记在发布队列，稿子不挂状态字段，列表只保留「发布中」这个瞬时信号。
3. 预览按需唤起：列表无常驻预览列，行内按钮开弹窗。
4. 版式跟着内容形状走：文章/音频用行，贴图用拼贴格子，视频用 16:9 封面格，「全部稿子」用统一紧凑行。
5. 栏底只留一个设置入口：平台账号与默认发布名单都收在设置里；只有凭据缺失时该行才冒出一个数字。
6. 平台账号一行说的是「哪个账号」：账号名 + 身份常显；点一下，凭据卡从设置弹窗**外侧**浮出来（账号 ID、授权有效期、最近校验、发布去向）。左列账号往左弹、右列往右弹，带箭头指着被点的那一行，不顶走下面的名单；窗口太窄放不下时退回视口内。
7. 默认发布平台四行各成一条横带（上下 18px 留白 + 一条细线），不再只靠行间距分开 —— 否则上一行的选中勾会贴到下一行的方块上。
8. 平台方块三种面貌：**选中 = 平台色填满** + 角上一枚勾；没选中 = 同色淡底（`color + "33"`，保留平台身份）；凭据没拿到 = 中性灰。默认名单与发布弹层共用同一套规则。
9. 发布队列里状态长在平台方块上：一篇稿子一行，进行中从方块底部涨水位，已发布右上角一枚勾且整块是直达链接，出问题整块换成统一的错误色、点一下重试。
10. 错误色只有一种（`--error:#C81E4E`）：发布失败、凭据获取失败、超限预检共用它；橙色回归成纯内容色（视频）。
11. 内容列只有一条宽度：头部与列表共用 `.w-canvas`（上限 1560px 居中），列表不再单独收窄。
12. 规模：筛选 O(n)、排序 O(n log n)；过千条需要窗口化渲染（本原型未做）。
13. 贴图支持长按拖拽排序：按住 220ms 拎起（轻点仍是打开这篇），拖动时其余格子实时让位（FLIP），松手滑回槽位落位。一拖就把排序档切到「自定义顺序」—— 否则下一次按时间排序会把刚排好的顺序抹掉。搜索中与按标题排时不开拖动，因为那时的顺序不是用户排的。
14. 标题全套按 Apple HIG 的层级做法重排，只留两级（对应 HIG 的 Title 1 / Title 2），两级共用字重与字距，**层级只靠字号差**：

    | 角色 | 字号 | 字重 | 字距 |
    |---|---|---|---|
    | 一级 · 栏目名 / 正在编辑的稿子（`.w-h1`、`.m-titlein`） | 28px | 700 | -0.4px |
    | 二级 · 弹层标题（`.m-sheet-head h2`） | 22px | 700 | -0.2px |
    | 三级 · 行标题 / 预览弹窗标题 | 17px | 700 | -0.2px |
    | 四级 · 格子标题 / 队列行 / 区块标题 | 15px | 700 | -0.2px |
    | 预览手机里的已发布标题 | 19px | 700 | -0.2px |

    改动前分别是 30/900、36/900、17/800、15/800，编辑页标题是 42/900 —— 靠字重顶到极端、字距压到 -1.5px 来撑层级。HIG 说层级要字号、字重、颜色一起调，且不要用极端字重。全部收敛到 700 之后，正文仍是 17px / 行高 1.85（HIG：长段落要松行距）。占位文字从 `#C9C4B8`（对比度 1.66:1）提到 `#8A8478`（3.55:1），正文 17.7:1 —— 占位仍是次要层级，但读得出来。
15. 按钮不参与这次收敛：它们是动作，沿用原来那套更重的字重，界面的"块感"留在动作上。
